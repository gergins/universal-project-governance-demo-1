# New idea kickoff — reusable instructions

I have an idea: [IDEA].
My newly created product repository is: [OWNER/REPO].
This product repository was created from [FRAMEWORK_REPOSITORY] at [FRAMEWORK_VERSION_OR_SHA].

First verify live repository identity and read its `AGENTS.md`, `docs/WHAT_HOW_MODEL.md`, `docs/CAPABILITY_CATALOGUE.md` and `docs/PROJECT_BRIEF.md`.
Focus on WHAT: discover the problem, users, research, domain, human experience, selected capabilities, risks, scope and acceptance.
Use HOW: select minimal appropriate workflows, tools, optional agents and independent verification.
Do not assume every catalogue entry needs development or that a configured tool exists. Propose/record a project brief and capability list with evidence and unresolved questions.
Execute only authorized operations using available tools; report unavailable CI and integrations as unverified. Preserve explicit handoffs.
